# Triage labels

| Canonical role | Tracker label |
| --- | --- |
| bug | bug |
| enhancement | enhancement |
| needs-triage | needs-triage |
| needs-info | needs-info |
| ready-for-agent | ready-for-agent |
| ready-for-human | ready-for-human |
| wontfix | wontfix |

Each triaged item carries exactly one category (`bug` or `enhancement`)
and one state. If state labels conflict, ask the maintainer before acting.
