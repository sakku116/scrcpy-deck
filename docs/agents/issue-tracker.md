# Issue tracker: GitHub

Issues and specs live in GitHub Issues for `sakku116/scrcpy-deck`.
Use the `gh` CLI with `--repo sakku116/scrcpy-deck`.

## Operations

- Create: `gh issue create`
- Read body, labels, author, dates and comments: `gh issue view <number> --comments --json number,title,body,labels,author,createdAt,updatedAt,comments`
- List: `gh issue list --state open`
- Comment: `gh issue comment <number>`
- Update labels: `gh issue edit <number> --add-label "..." --remove-label "..."`
- Close: `gh issue close <number>`

Paginate discovery queries so all matching issues are considered.
“Publish to the issue tracker” means create a GitHub issue.
“Fetch the relevant ticket” means read the full issue and comments.

## Pull requests as a triage surface

**PRs as a request surface: no.**

Discovery includes issues only. Explicitly named PRs can still be triaged:
read their body, comments, labels and diff using `gh pr view` and `gh pr diff`.

GitHub shares issue and PR numbers. Resolve a bare `#number` as a PR
or issue before acting.

## Triage disclaimer

Every issue or comment posted during triage must start with:

> *This was generated by AI during triage.*
