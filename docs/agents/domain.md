# Domain docs

This repository uses a single-context layout:
root `CONTEXT.md` and `docs/adr/`.

## Before exploring

Read root `CONTEXT.md` and ADRs relevant to the area.
If `CONTEXT-MAP.md` exists, follow it to the relevant context documents.

If these documents are absent, proceed silently. Domain modeling creates
them when terms or decisions are resolved.

## Vocabulary and decisions

Use domain terms defined in the relevant `CONTEXT.md`.
Surface conflicts with existing ADRs explicitly before proposing changes.
